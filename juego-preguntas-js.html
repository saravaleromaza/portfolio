Juego de preguntas

Mini juego de preguntas en JavaScript con cuenta atrás de 30 segundos, pantalla de Game Over con sonido y opción de volver a intentarlo.

  • JavaScript
  • HTML
  • CSS
Ver en GitHub (se abre en una pestaña nueva) Ver más proyectos

Qué hace

Un juego de preguntas que se juega en el navegador. Hay 5 preguntas y una cuenta atrás de 30 segundos: si se acaba el tiempo, aparece la pantalla de Game Over con un sonido. También se puede terminar antes con el botón Finalizar y empezar de nuevo con Volver a intentar.

Qué aprendí

  • A manipular el DOM con JavaScript: mostrar las preguntas, leer las respuestas y cambiar la pantalla según el estado del juego.
  • A controlar el tiempo con temporizadores y a detenerlos y reiniciarlos correctamente.
  • A reproducir audio desde JavaScript y a reiniciar el estado del juego sin recargar la página.

Cómo ejecutarlo

No necesita instalar nada. Descarga el proyecto:

git clone https://github.com/saravaleromaza/juego-preguntas-js.git
cd juego-preguntas-js

Abre index.html en el navegador, o sírvelo con la extensión Live Server de VS Code.

Aquí se puede ver la demo en directo
