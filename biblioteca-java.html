biblioteca-java

Aplicación de consola en Java para gestionar el inventario de una biblioteca.

  • Java
Ver en GitHub (se abre en una pestaña nueva) Ver más proyectos

Qué hace

Aplicación de consola en Java para llevar el inventario de una biblioteca. Desde la terminal se puede:

  • Agregar libros al inventario.
  • Mostrar los libros que hay registrados.
  • Buscar libros dentro del inventario.

Qué aprendí

  • Aprendí a trabajar con diferentes clases y constructores en Java, creando objetos y utilizando ArrayList para almacenar y gestionar información
  • Uno de los retos fue controlar las búsquedas de libros no encontrados y gestionar los datos introducidos por el usuario, resolviéndolo mediante condicionales y variables booleanas.

Cómo ejecutarlo

Necesitas tener instalado el JDK de Java. Descarga el proyecto:

git clone https://github.com/saravaleromaza/biblioteca-java.git
            cd biblioteca-java

Abre el proyecto en tu IDE (IntelliJ IDEA, Eclipse, VS Code...) y ejecuta la clase Main
