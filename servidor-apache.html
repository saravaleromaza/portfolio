Qué hace

Instalación del servidor web Apache sobre Ubuntu Server, dentro de una máquina virtual, y publicación de una página web estática.

Qué aprendí

  • Aprendí a instalar y configurar Apache en Ubuntu Server dentro de una máquina virtual, y a publicar una página web estática para que pudiera servirse desde el servidor
  • Uno de los retos fue configurar correctamente el servidor y comprobar que la página web se mostraba desde el navegador. Lo resolví siguiendo los pasos de configuración y verificando el acceso a la web

Cómo ejecutarlo

Pasos generales para reproducirlo en un Ubuntu Server:

sudo apt update
                  sudo apt install apache2
                  sudo systemctl status apache2
                  sudo cp miweb.html /var/www/html/

Después abre http://IP-DE-LA-MAQUINA/miweb.html desde el navegador.
