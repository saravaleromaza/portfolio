el-sabor-de-la-abuela

Web sencilla de restaurante con carta y reservas, hecha con HTML y CSS.

  • HTML
  • CSS
Ver en GitHub (se abre en una pestaña nueva) Ver más proyectos

Qué hace

Web sencilla para un restaurante, hecha con HTML y CSS. Incluye:

  • La carta del restaurante.
  • Un apartado de reservas.

Qué aprendí

  • Aprendí a estructurar una página web con HTML5 y a darle estilo con CSS3
  • Uno de los retos fue organizar los diferentes apartados de la web para que tuvieran un diseño coherente y fueran fáciles de navegar

Cómo ejecutarlo

Descarga el proyecto y ábrelo en el navegador:

git clone https://github.com/saravaleromaza/el-sabor-de-la-abuela.git
          cd el-sabor-de-la-abuela

Abre el archivo index.html con el navegador, o con Live Server desde VS Code.
