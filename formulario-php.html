formulario-php

Formulario de registro en PHP con validación del lado del servidor y protección contra XSS.

  • PHP
  • HTML
  • CSS
Ver en GitHub (se abre en una pestaña nueva) Ver más proyectos

Qué hace

Formulario de registro desarrollado con PHP, HTML5 y CSS3. Lo más importante del proyecto está en cómo trata los datos:

  • Validación robusta del lado del servidor.
  • Filtrado de los datos recibidos.
  • Protección contra XSS.
  • Interfaz limpia con HTML5 y CSS3.

Qué aprendí

  • Aprendí a desarrollar formularios con HTML5 y CSS3 y a procesar y validar los datos recibidos mediante PHP
  • Abordar mediante la validación y el filtrado de los datos en el servidor, así como medidas de protección frente a ataques XSS

Cómo ejecutarlo

Necesitas tener PHP instalado. Descarga el proyecto y arranca el servidor local de PHP desde su carpeta:

git clone https://github.com/saravaleromaza/formulario-php.git
                cd formulario-php
                php -S localhost:8000

Después abre http://localhost:8000/formulario-php en el navegador.
